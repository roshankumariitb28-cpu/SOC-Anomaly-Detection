## Model Weights

The trained model generated two weight files:

- **best.pt** – Best-performing model based on validation results.
- **last.pt** – Final checkpoint saved after training.

Both files are approximately **41.3 MB** in size.

Since GitHub's web interface only allows files up to **25 MB**, the weight files are **not included** in this repository.

The repository contains:
- Source code
- Training scripts
- README
- Training results (`results.csv`, `results.png`)
- Sample training images

The trained weights can be shared separately using **Google Drive** or **Git Large File Storage (Git LFS)** if required.
